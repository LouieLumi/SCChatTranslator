SC CHAT TRANSLATOR / QUICK GUIDE

星际公民聊天翻译
配图使用说明

在游戏旁边读取公开频道、翻译聊天，也可以输入中文后发送英文。先进入服务器，再打开程序即可开始。

v0.5.3Windows 10 / 11 · 64 位单个 EXE · 无需安装 Python本说明可离线查看
开始使用浮窗与滚动输入与发送F12 联动模型与设置托盘与常见问题

01第一次打开

① 进入游戏服务器

用 RSI Launcher 正常登录，进入游戏服务器后保持游戏运行。

② 双击 EXE

打开同文件夹内的“星际公民聊天翻译.exe”。首次会准备内置环境和模型，等待进度完成。

③ 查看聊天

默认自动跟随当前角色的公开服务器频道。出现消息后即可查看原文和译文。

建议游戏使用“无边框窗口”模式，方便浮窗显示在游戏上方。更新 EXE 会保留原来的设置；首次使用默认采用内置 Argos 模型。

02浮窗：查看、移动、锁定

位置 / 动作作用
右上角齿轮打开设置：选择频道、模型、原文显示和透明度。
右上角锁图标点击切换锁定 / 解锁。解锁后拖动窗口上沿来移动，拖动边缘或角落调整大小；锁定后固定位置，保持置顶。
右上角 ×隐藏到系统托盘，继续在后台读取。彻底退出请使用托盘右键菜单。
鼠标移到三个按钮处按钮淡入；鼠标离开 3 秒后淡出。

滚动条只在你滚动时出现

默认隐藏；收到新消息自动滚动时也不显示。鼠标滚轮滚动聊天时显示，停止滚轮操作 3 秒后淡出。再次滚动会重新计时。

03按回车输入，选择“中 / 英”发送

操作结果
按 Enter显示输入框并开始输入。在游戏里使用时，需要先按下一节开启 F12 联动并确认原生聊天框已隐藏。
点击 中 / 英直接切换，不弹下拉菜单。中：按本机汉化字库编码发送中文；英：中文自动译为英文后发送，英文原文直接发送。
有内容时按 Enter 或点箭头提交发送；成功后清空并隐藏。失败时保留草稿和错误提示。
空内容时按 Enter直接收起，不发送任何消息。只有空格也按空内容处理。
按 Esc、点击回游戏或切到其他窗口收起输入框，保留未发送的草稿；再次按回车可继续编辑。

中文能否被其他人看到？“中”模式使用与 SC 盒子同类的 [zh] @… 社区输入编码。接收方加载兼容的汉化社区输入法码表后才能还原成中文；没有对应码表时可能看到编码。与国际玩家交流可选择“英”。

发送到当前选中的公开频道。若出现超时，先确认频道里是否已经收到消息，再决定是否重发。

04游戏里的 F12 / 回车联动

  1. 打开设置，勾选 “F12 状态确认 / 回车输入”，点击“保存并应用”。
  2. 回到游戏按 F12。游戏先切换原生聊天框，随后本程序询问实际状态。
  3. 按你看到的游戏画面选择：原生聊天框已消失，点 “已隐藏”；仍在显示，点 “仍显示”。
选择“已隐藏”
在游戏中按回车，使用本程序输入框；再按回车发送。
选择“仍显示”
回车继续使用游戏原生输入框，本程序不接管。

这是你确认后同步的状态，不是自动识别游戏画面。程序 / 游戏重启后、尚未选择状态时，回车保留原生行为。若在游戏菜单里改了聊天框状态，请重新按 F12 确认，或到设置修正状态。

05频道、翻译模型与透明度

日常设置

  • 聊天频道：默认“自动跟随当前服务器”。出现多个公开频道、内容与游戏不符时，手动选择对应频道。
  • 显示原文：关闭后只显示外语译文；中文消息仍显示中文。
  • 背景透明度：向右拖动更透明，只调整背景，文字保持清晰。
  • 游戏 LIVE 目录：通常自动识别。无法找到时，点“选择”，选中 LIVE 目录中的 loginData.json，或 Bin64 目录中的 StarCitizen.exe。
  • 保存并应用：修改完成后点击保存；直接关闭设置会取消未保存的调整。

如何选择模型

模型适合的用法
Argos（默认）模型已内置，离线使用，Windows CPU 运行。
Hy-MT3 1.8B 本地在 Windows 本地运行；首次下载约 1.35 GB 模型及运行组件，准备期间使用 Argos。
自定义 API调用 Mac 或其他服务器上的模型，需填写地址、密钥（如需）和模型名称。

使用 Mac / 服务器上的翻译 API

  1. “翻译模型”选择 “自定义翻译 API · Mac / 其他服务”。
  2. 填入服务地址，例如 http://你的服务器IP:端口/v1。服务需兼容 Chat Completions 接口。
  3. 如服务需要认证，填入 API 密钥。
  4. 点击“获取模型”后选择模型，或直接填写服务提供的模型名称。
  5. 点击“测试翻译连接”，成功后“保存并应用”。

本机 Hy 准备期间或 API 不可用时，程序会回退到内置 Argos。使用远程 API 时，需要翻译的聊天文字会发送给你填写的服务。

程序内置 4,262 条精选中英游戏术语作为翻译参考。收到汉化编码时，会读取本机已有汉化字库尝试还原；本程序不安装或修改汉化。

06窗口不见了，以及其他常见情况

点击 × 后，怎么重新打开？

在 Windows 任务栏右下角通知区域找到程序图标，可能在 ^ 隐藏图标列表里。双击图标恢复窗口；也可右键选择“显示聊天窗口”。想彻底退出，右键选择“退出”。

没有聊天，或者频道不对

确认已经进入游戏服务器，再检查设置中的 LIVE 目录和聊天频道。若账号返回多个公开频道，请手动选择。游戏更新也可能影响读取接口。

按回车没有打开我们的输入框

先勾选 F12 联动并保存，回到游戏按 F12，再确认“已隐藏”。如果选择“仍显示”或状态未知，回车会留给游戏。也可点击本程序窗口后按回车输入。

窗口在桌面能看到，进游戏就看不到

尝试将游戏改为“无边框窗口”，再锁定浮窗。独占全屏模式不保证普通桌面浮窗可见。

能否直接复制 EXE 到其他电脑？

可以，双击运行即可。模型和公开术语库随 EXE 提供；个人 API 密钥、游戏登录信息和聊天记录不在 EXE 内。新电脑需要自己的游戏登录及必要的 API 设置。
